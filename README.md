# Hadj Abdelkader Benzater

Telecommunications researcher and PhD candidate at **École Militaire Polytechnique (EMP), Algiers**.

I study cooperative compressed spectrum sensing, joint sparse recovery and
sub-Nyquist acquisition, connecting algorithms with SDR and RF receiver design.
My research tools include MATLAB, Python, GNU Radio and USRP platforms.

[Research website](https://lhadjbenzater.github.io/) · [Google Scholar](https://scholar.google.com/citations?user=EIegGugAAAAJ) · [ORCID](https://orcid.org/0009-0006-2533-0315) · [Web of Science](https://www.webofscience.com/wos/author/record/KBB-2975-2024)

## Start with a runnable example

Download a repository release, open its directory in MATLAB, and run the command
below. Each new example generates its inputs and writes figures and numerical
outputs. The repository README documents assumptions, MATLAB requirements and
the scope of the associated paper experiments.

| Research project | MATLAB quick start |
|---|---|
| [MRMP: joint sparse recovery](https://github.com/LhadjBENZATER/Multivector-Redused-set-Matching-Pursuit) | `demo_mrmp` |
| [Cooperative spectrum sensing](https://github.com/LhadjBENZATER/Cooperative-Compressed-Spectrum-Sensing) | `demo_ccss` |
| [Sparse support tracking](https://github.com/LhadjBENZATER/Support-Tracking-in-CS) | `demo_support_tracking` |
| [Overlapping-subband fusion](https://github.com/LhadjBENZATER/Overlap-and-Correlation-based-fusion-rule) | `demo_fusion` |
| [LNA gain and noise figure](https://github.com/LhadjBENZATER/LNA-Design) | `demo_lna` |

**Suggested starting point:** the MRMP example compares the reference solver
with SOMP on paired physical and virtual measurements. It reports bin-level
Pd, Pf, F1 and measured elapsed time.

These demonstrations use synthetic or analytic inputs. They are distinct from
the papers' full numerical campaigns and hardware recordings. Numerical checks
and example generation run automatically in MATLAB R2024a on GitHub Actions.

## Research interests

- Cooperative spectrum sensing, virtual data synthesis and decision fusion.
- Greedy sparse recovery and multiple-measurement-vector models.
- Practical compressed acquisition, SDR validation and RF gain–noise trade-offs.
